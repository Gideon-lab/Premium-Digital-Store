PREMIUM.ID — Website Premium Digital

Struktur:
- index.html  -> struktur halaman
- script.js   -> produk, harga, filter, WhatsApp, FAQ
- README.txt  -> panduan

Cara setup:
1. Buka index.html untuk preview.
2. Buka script.js.
3. Ganti:
   const WHATSAPP_NUMBER = "6281234567890";
   dengan nomor WhatsApp kamu.
4. Edit array products untuk mengubah produk, kategori, harga, dan emoji.
5. Untuk hosting, upload index.html dan script.js dalam folder yang sama.

Tidak menggunakan framework atau dependency eksternal.
